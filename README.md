# EXA Analytics — Dashboard Unificado

3 verticais em um único HTML · Segurança · Seguros · Conteúdo · mai/2026

## Deploy
```bash
npm i -g vercel && cd exa-analytics-dashboard && vercel
```

## Estrutura
- Menu superior fixo: alterna entre Segurança (azul) / Seguros (verde) / Conteúdo (âmbar)
- Sidebar lateral: navegação interna dentro de cada vertical
- Self-contained: zero CDN, zero dependências externas
